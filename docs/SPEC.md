# うみづり 仕様書

スマホ縦画面向けの 2D ドット絵釣りゲーム。GitHub Actions で GitHub Pages に配信する。

## 1. 技術構成

| 項目 | 決定 |
| --- | --- |
| 言語/ビルド | TypeScript + Vite（フレームワークなし） |
| 描画 | Canvas 2D。内部解像度 **360×640** を画面幅に合わせてニアレストネイバー拡大 |
| 素材 | ドット絵はすべてコード内に文字列マップ＋パレットで定義し、起動時にオフスクリーン Canvas に焼き込む（外部画像なし） |
| 画面 | 縦 640 固定。縦長のスマホでは幅 360 で、余った上下は画面端の色を延長。横長の PC・タブレットでは画面の縦横比に合わせて海を横に広げる（最大 16:9、それより横長なら左右に帯）。船と釣り糸は常に中央、各層の魚の数は幅に比例して増やし密度を保つ |
| フォント | DotGothic16（Google Fonts）。読めない場合はシステムフォント |
| サウンド | Web Audio API による 8bit 風の合成効果音のみ（BGM なし）。右上でミュート切替 |
| 振動 | テンション危険域で `navigator.vibrate`（対応端末のみ） |
| 保存 | ハイスコアを `localStorage` に保存 |
| テスト | Vitest（ゲームロジックの純粋関数） |
| デプロイ | `main` への push で 型チェック → テスト → ビルド → GitHub Pages。PR ではテストとビルドのみ。Vite の `base` は `/cc_fishing/` |

> GitHub のリポジトリ設定 → Pages → Source を「GitHub Actions」にする必要がある。

## 2. 画面構成

1. **タイトル**: 海と船の背景（魚が泳ぐデモ）、ロゴ「うみづり」、「TAP TO START」、ハイスコア。
2. **プレイ**: 下記。
3. **リザルト**: 合計スコア、ハイスコア更新表示、釣った魚の内訳（アイコン×匹数と小計）。表示から約 1 秒後以降、画面のどこをタップしてもタイトルへ戻る（連打の勢いで誤って戻らないように待つ）。

## 3. プレイ画面

### 3.1 レイアウト（1 画面固定・スクロールなし）

- 上部: 空と海面。釣り船に釣り人が乗り、竿先から糸がまっすぐ垂れる。
- 海: 上から浅層・中層・深層。水色 → 紺色のグラデーション。差し込む光。
- 海底: ごつごつした岩。
- 下部: 操作パネル。丸いボタン 1 つのみ。ただし画面のどこをタップ・長押ししても、このボタンと同じ操作になる。
- HUD: 左上に残り時間、右上にスコアとミュートボタン。

### 3.2 ゲームの流れ

- 制限時間 **90 秒**。対決中もタイマーは進む。カットイン中のみ停止。
- 時間切れ時に対決中なら、その対決の決着まで続行してからリザルトへ。
- 開始と同時に釣り人が糸を垂らし、針が自動で沈み始める。

### 3.3 針の操作（通常時）

- 放置: 針はゆっくり沈む。海面 → 最深部まで約 **10 秒**。
- 最深部は海底の岩から少し浮いた位置（岩には接触しない）。
- タップ: 全深度の約 **4%** 分だけ針が上がる。
- 長押し: 巻き続けて海面方向へ移動。最深部 → 海面を約 **3 秒**。
- 海面より上には行かない。

### 3.4 フッキング（食いつき）

- 針と魚が接触している状態でボタンを **押した瞬間** のみ判定する（長押しで巻いている途中に重なっても食いつかない）。
- 接触判定は魚体の矩形を約 80% に縮めた範囲。
- 複数の魚と重なっている場合は針に最も近い魚。
- 食いついた魚は口が針に来るよう位置を補正し、頭を上に向けた姿勢になる。

### 3.5 対決（テンションゲージ）

- 魚の右側に縦長のテンションバーを表示。色は上から 赤・黄・緑・黄・赤。
- 食いついた時点で目盛りは中央。
- タップ 1 回ごとに: 魚が一定距離上昇し、テンションが上昇する。
- 放置するとテンションは徐々に下降し、魚は少しずつ沈む（深層魚ほど引きが強い）。
- 魚の暴れ: ランダムにテンションを上下に揺さぶる。深い層・高得点の魚ほど強く頻繁。
- 対決中の長押しは 1 回のタップ扱い（巻き続けはしない。連打が必要）。
- テンションが **最大** に達する → 糸が切れる（失敗）。
- テンションが **最小** に達する → 逃げられる（失敗）。
- 魚が海面に到達 → 釣り上げ成功 → カットイン。
- 危険域（赤）では振動と警告表示。

### 3.6 成功・失敗後

- 成功: カットイン終了後、針は海面から再び沈み始める。
- 失敗: 「糸が切れた！」/「逃げられた…」を約 1 秒表示し、針は海面から再投入。
- 失敗のペナルティは時間ロスのみ。

### 3.7 カットイン

- 約 2.5 秒。タップでスキップ可。
- 集中線＋水しぶきパーティクルの背景に、該当魚のドット絵を拡大して斜めに跳ね上がらせる。
- 右下に斜め区切りのパネルで釣り人の笑顔。
- 「マダイ GET!! +50pt」を表示。
- 深層魚は画面フラッシュとレア度表示で豪華に。

## 4. 魚

### 4.1 行動

- 各層の高さの帯の中を横方向に泳ぎ、少し上下にゆらぐ。
- 画面外へ出たら消え、一定時間後に左右どちらかから新しく出現。
- 常時の数: 浅層 約 8 匹（アジ・サバは群れ）、中層 約 4 匹、深層 約 3 匹。
- 高得点の魚ほど出現率が低く、泳ぎが速い。
- 釣った魚は消え、時間を置いて補充。

## 5. 調整用定数

速度・テンション増減・暴れ幅・出現数などはすべて `src/config.ts` と `src/fish.ts` に定数としてまとめ、後から調整できるようにする。
